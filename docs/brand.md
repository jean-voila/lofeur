# lofeur visual identity

- Logo: `public/logo.svg`, an original headphone mark with a relaxed smile.
- Palette: pine `#315c53`, cream `#f4e6d2`, chocolate `#1d181a`.
- Banner: `docs/assets/banner.png`, generated with the built-in image-generation
  tool on 25 October 2026. The banner is a brand illustration, not an application
  screenshot. The preview PNGs are actual browser captures.

## Banner prompt

> Use case: ads-marketing. Create a beautiful wide horizontal GitHub README banner
> for an open-source lofi focus web app named 'lofeur'. Warm hand-drawn anime
> illustration, a quiet attic study at dusk, large window on right with blue
> lavender night sky and town rooftops, cozy desk, amber desk lamp, record player,
> sleeping orange cat and plant. Dark chocolate brown and warm cream, muted pine
> green accents. On the left clear large chunky rounded cream lowercase wordmark
> exactly 'lofeur', with small text underneath exactly 'tune in. slow down.' Refined
> cinematic composition, subtle paper grain, generous negative space around
> typography. No UI mockup, no badges, no extra text. Wide 3:1 landscape composition.
